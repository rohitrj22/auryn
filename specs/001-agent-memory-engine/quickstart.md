# Quickstart: validating Auryn

This guide proves the feature works end to end. It is what a judge follows, and
what the 15:00, 18:00 and 20:00 gates check.

## Prerequisites

- A container runtime that can run `docker compose`
- Python 3.13 or newer, and `uv`
- **No API key.** Everything below runs without one.

## Setup

```bash
docker compose up -d          # starts FalkorDB on port 6379
uv sync                       # installs falkordb and pytest
uv run python -m proofs.run_all
```

Expected: five `PASS` lines and exit code 0.

> Build-machine note, not for the README: if your Docker install enforces a
> sign-in, point `DOCKER_HOST` at another container runtime's socket. If host
> port 6379 is taken, set `AURYN_PORT` to a free port. A judge needs neither.

## The five proofs

Each maps to one Track 02 criterion and prints its own result.

### 1. Memory outlives the process

```bash
uv run python -m proofs.persistence
```

Runs a session, states a fact, exits the process completely, starts a second
process with an empty prompt, and asserts the fact comes back.

**Pass**: the second process reports the fact without being told it.
**Checks**: FR-012 to FR-015, SC-001. User Story 1.

### 2. Three kinds, recalled separately

```bash
uv run python -m proofs.memory_kinds
```

Writes one of each kind, then asks for each kind alone, then asks without a
kind. Also writes a contradicting fact and asserts the older one is flagged, not
deleted. Also writes enough events about one subject to trigger derivation, and
asserts the derived fact links back to its events.

**Pass**: each request returns only its own kind; supersession and derivation both hold.
**Checks**: FR-001 to FR-007, FR-016, SC-002. User Story 2.

### 3. One agent picks up another's work

```bash
uv run python -m proofs.handoff
```

Runs the Triage agent to completion, then starts the Refund agent **in a
separate process** with only a tenant and a task id.

**Pass**: the second agent states the first agent's facts and takes the right
next step. The proof also asserts no message object passed between them.
**Checks**: FR-017 to FR-020, SC-003. User Story 3.

### 4. Tenant isolation, at scale

```bash
uv run python -m proofs.isolation --tenants 1000
```

Creates tenant graphs through the engine, counts them with `GRAPH.LIST`, reads
memory cost from `INFO memory`, then attempts cross-tenant reads.

**Pass**: the graph count matches, and every cross-tenant read returns zero rows.
**Measured on the build machine**: 1,000 graphs, 2.94 s to create, 470 MB total,
about 459 KB per tenant, all reclaimed on delete.
**Checks**: FR-021 to FR-024, FR-048, FR-049, SC-004, SC-017, SC-018. User Story 4.

### 5. Concurrency, measured honestly

```bash
uv run python -m proofs.concurrency --procs 8 --seconds 30
```

Generates mixed reads and writes from several processes, then reports both sides.

**Pass**: zero lost writes, and a complete report.
**The report must state**: client throughput, server `p50`/`p99`/`p99.9` from
`INFO latencystats`, `rejected_calls` and `failed_calls`, the configuration it
ran against, Auryn's own overhead as the client-server gap, and a named cause
for whatever limited the run.
**Baseline measured**: one connection reaches about 1,100 writes/sec and 970
indexed reads/sec, while the server answers in 525 µs, so a single process is
the limit, not FalkorDB.
**Checks**: FR-030, FR-041 to FR-047, SC-005, SC-015, SC-016. User Story 5.

## Principle I: the graph must be doing the work

```bash
docker compose stop falkordb
uv run python -m proofs.graph_required
```

**Pass**: every proof fails, and each names FalkorDB as unavailable. Nothing
answers from memory.
**Fail**: anything still works. That would mean a second store exists, which
Constitution Principle I forbids and hackathon rule 3 disqualifies.

Restart with `docker compose start falkordb`.

## Recall quality, measured

```bash
uv run python -m evals.run_eval
```

Builds a labelled fixture of about 200 memories across 20 tenants with about 40
labelled requests, then reports precision@5, recall@5 and mean reciprocal rank.
Deterministic and offline. Exits non-zero if quality falls below the threshold.

**Checks**: FR-036 to FR-040, SC-013, SC-014.

## Speed evidence for the README

```bash
uv run python -m proofs.bench.report --profile
```

Prints the recall query's execution plan before and after indexing, both
timings, and the `Cached execution` flag proving plan reuse.

**Checks**: FR-050 to FR-055, SC-019, SC-020.

## With a real model

```bash
cp .env.example .env     # then add your own GEMINI_API_KEY
uv run python -m demo.run
```

The agents' wording is now generated by `gemini-3.8-flash`, and the model itself
decides what to remember. Every proof above still passes unchanged.

**Checks**: FR-025 to FR-027, SC-008.

## The grep that enforces the layering

```bash
uv run pytest tests/unit/test_layering.py
```

Asserts `auryn/` contains no demo vocabulary and imports nothing from `demo/`.

**Checks**: FR-033, FR-034, SC-010. Constitution Principle III.
